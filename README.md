## `$ ls featured_projects/`

<details open>
<summary><b>🧬 Topology-Guided Explainable Deep Learning for Skin Cancer Classification</b></summary>
<br/>

A dual-evidence dermoscopic image classifier that fuses **deep visual features** with **topological/geometric lesion descriptors** (persistent homology), explained via Grad-CAM + SHAP.

| | |
|---|---|
| **Stack** | Python, PyTorch, ViT-B/16, EfficientNet-B3, MobileNetV3, U-Net, Ripser/Gudhi, Grad-CAM, SHAP |
| **Scale** | HAM10000 (10,015 images) + PH2 external validation |
| **Impact** | **89.00%** accuracy (ViT-B/16 Partial-4) and **0.9383 ROC-AUC** (ViT-B/16 Partial-2) on PH2 external evaluation |

🔗 [View Repository](https://github.com/ManasMondal2025/Topology-Guided-Explainable-Deep-Learning-for-Skin-Cancer-Classification-Using-Dermoscopic-Images)

</details>

<details>
<summary><b>🎬 Unified Video-Text Grounding System (UnVTG)</b></summary>
<br/>

A transformer-based system that localizes the temporal segment of a video matching a natural language query — combining video feature extraction with text-query understanding for temporal action grounding.

| | |
|---|---|
| **Stack** | Python, PyTorch, Transformers, OpenCV, Decord, SciPy |
| **Scale** | Full video-text grounding pipeline: feature extraction → joint transformer architecture → temporal localization |
| **Impact** | Predicts start/end time + confidence score for natural-language video queries |

🔗 [View Repository](https://github.com/ManasMondal2025/Unified-Video-Text-Grounding-System)

</details>

<details>

| | |
|---|---|

</details>

<details>
<summary><b>📄 Project Akshar</b></summary>
<br/>

An intelligent, multi-module document processing and AI pipeline handling the complete lifecycle of physical and digital documents — from image ingestion, dewarping, and layout analysis, through OCR, to Vector Database indexing and RAG inference. Built as 4 independent modules: a FastAPI + React orchestrator, an ML-based dewarping engine, a local OCR layout pipeline, and a RAG/vector-search backend.

| | |
|---|---|
| **Stack** | Python, FastAPI, React/Vite, PyTorch (CNN corner detection), PaddleOCR + PaddleX, PyMuPDF, ChromaDB, BAAI/bge-base-en-v1.5 embeddings, Ollama (Llama-3) |
| **Scale** | 4-module pipeline: Orchestrator → ML Dewarping → Layout/OCR → RAG + Vector DB |
| **Impact** | Turns raw physical/digital documents into a searchable, visually-grounded, RAG-ready knowledge base with verifiable answers |

🔗 [View Repository](https://github.com/ManasMondal2025/Project-Akshar)
